# Job Command Center

Native desktop app (Mac, Windows, Linux) that turns job postings into tailored, ATS-checked resumes with AI agents. It can also be opened from a phone or another computer through the built-in web companion.

**Want to use it?** Download it for your computer, no coding needed: [Mac, Windows and Linux instructions](app/README.md#get-the-app-no-coding-needed).

[Screenshots and how it works](app/README.md#what-it-looks-like).

The app lives in [`app/`](app/); see [app/README.md](app/README.md) for running from source, building and development notes. Installers are built by [.github/workflows/desktop.yml](.github/workflows/desktop.yml).
